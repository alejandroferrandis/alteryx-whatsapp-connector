Connection

A profile is one linked WhatsApp account on this machine. Leave it as default unless you need to read more than one account.

First time here? Tick Link this device, type the phone number of the WhatsApp account below, and run the workflow. Designer will show an 8-character code. On that phone open WhatsApp › Settings › Linked devices › Link a device › Link with phone number instead and type the code. Then untick the box and run again to read messages.

Leave empty to link with a QR code instead, which is printed in the results pane.

What to read

Sync connects to WhatsApp, collects everything that arrived since the last run, stores it, and returns it. Archive only re-reads what earlier runs already collected without connecting - useful for re-running a workflow offline.

One per line, or comma separated. Accepts a chat name, a phone number, or a chat id. Leave empty for every chat. Chat ids are listed on this tool's second output anchor - run it once with this box empty and look at Chats.

Keep this on for scheduled workflows: every run returns exactly what is new. Turn it off to re-read history, then use the date range below.

WhatsApp holds messages for a linked device while it is offline and delivers the lot on reconnect. With this on, the moment you linked marks the start of time for this profile, so a fresh link never pulls in old conversations. Anything sent after you linked still arrives, including while you were setting the workflow up.

Protects a scheduled workflow that has been paused. If it has not run for a month, this stops a month of conversation arriving at once. Anything skipped is counted in the Results pane, never dropped silently.

Both ends are inclusive whole days in your local time, so "from today to today" covers all of today. The run log prints the exact UTC window it used.

Attachments

Files are saved next to the profile and their full path appears in the MediaPath column.

Advanced

WhatsApp delivers everything you missed in a burst as soon as the tool connects, so a short quiet period reliably means "that was all of it".
