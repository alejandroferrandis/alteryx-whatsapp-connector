Connection

A profile is one linked WhatsApp account on this machine. Use the same profile name as the WhatsApp Input tool to share one linked device.

First time here? Tick Link this device, type the phone number of the WhatsApp account below, and run the workflow. Designer will show an 8-character code. On that phone open WhatsApp › Settings › Linked devices › Link a device › Link with phone number instead and type the code. Then untick the box and run again to send.

Leave empty to link with a QR code instead, which is printed in the results pane.

Send to

A destination can be a phone number in any format (+1 555 0100, 0015550100), a chat id (120363000000000000@g.us for a group), or the name of a chat this profile already knows. Chat names come from the WhatsApp Input tool's Chats anchor, so run that once first.

Lets a column of local numbers such as 5550100 work as-is. Digits only, no +. Numbers that already carry a country code are left alone.

Message

Attachment (optional)

Images and videos are sent so they preview in the chat; anything else is sent as a document keeping its filename. Leave unset to send text only.

Leave unset and the message text becomes the caption, so one row sends one message rather than two.

Advanced
Pace matters. WhatsApp suspends accounts that behave like broadcasters. The default of 20 messages per minute is a gentle default. Raise it only for chats that expect the traffic, and never use this tool for unsolicited messaging.

Off by default: every row is reported on the output anchor with a Success flag and an Error message, so failures can be routed instead of stopping the run.

Must match the WhatsApp Input tool, or they will not share a linked device.
